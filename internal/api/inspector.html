Memory

Inspect what SecondContext learns from your conversations. Learning starts off. Your account identity keeps personal observations separate from other users.

Credentials stay in this page’s memory and are sent only to this server. They are not saved in browser storage.

Pause cancels unfinished capture and stops learning new observations. Existing memories remain available. The temporary-question control below applies to that question; other clients must select temporary chat in each request. It disables learning and personal-memory retrieval, while leaving reference knowledge independent.

Meeting notes

Paste notes or upload a text, Markdown, PDF or DOCX file. Choose how to use them. Personal observations require learning to be enabled and appear below when capture completes. Reference material stays in your private knowledge collection and does not create personal observations.

PDF and DOCX are detected from file bytes. Personal imports support up to 64 KiB of parsed text and extract at most 16 observations. Check the extracted claims and correct or forget any that are wrong. Reimporting the same note/date will not recreate forgotten observations. Reference copies are managed separately in the knowledge service.

Try a fresh conversation

Each question starts fresh, so you can check recall after a correction or forgetting. You can also ask “What do you remember about Alex?”, “Correct memory <ID or phrase> to <new observation>”, or “Forget memory <ID or phrase>”. Several matches require a specific ID.

Reference knowledge remains available. Temporary questions still follow the server’s conversation retention policy; this is not a transcript-erasure control.

Evidence used in an answer

Paste the memory IDs from the answer’s X-SecondContext-Memory-Ids header (or Responses context_packet). This shows the current observations; corrections, expiry and forgetting take effect here too.

Observations

Search current summaries and people/topic labels. Corrections change the stored summary and invalidate dependent summaries; original source, labels and expiry stay visible. Forget removes this observation from personal memory; a matching old transcript will not recreate it. Dialogue still supplied by your chat client can remain visible to the model.
